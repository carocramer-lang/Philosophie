# KI-Workshop-Sammler

Sammel-Tool fuer SuS: Lieblings-Prompts, AHA-Momente, Ideen, kritische Beobachtungen.
localStorage-Persistenz, Export/Import als JSON, Bild-Upload mit Resizing.

## Status
Platzhalter. Lege deine bestehende Datei hier als `index.html` ab und loesche die vorhandene Platzhalter-Datei.

## Test ergaenzen
Nach dem Ablegen eine `test.js` nach dem Muster aus `../hoehle-gezogen/test.js` anlegen.
Sobald `test.js` existiert, laeuft sie automatisch bei `npm test` mit.

## Persistenz
localStorage-Key nach Schema `<projekt>_v<n>` vergeben, siehe `docs/konventionen.md`.
